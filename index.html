Async Art — living works: the 342 Async Art works by Hulki Okan Tabak, Athena Novo and Mad Monk, shown live — every state side by side, the state for the current time, and the layers each is built from.

This is a preservation archive. Each work listed here had its files on a host that has since died, or on a centralized server, or on an IPFS address that no node still provides (checked twice through IPFS routing) and that OpenSea's IPFS gateway no longer serves. A copy of what could still be retrieved was placed on the public IPFS network; the content identifier (CID) of each saved file is given with links to three public IPFS gateways, in the order to try them (gateway.pinata.cloud, ipfs.io, dweb.link), together with where it came from and when. Works whose files are on IPFS and pinned, or fully on-chain, need no saved file; each collection page lists the held ones on IPFS in a table under the cards. Artists are credited as named in the works' own metadata. Nothing here is offered for sale or as a substitute for the original token.

Each work has one or more saved files: the image or video, and the metadata record.
