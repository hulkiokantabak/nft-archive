About the work

If Only You Were Yourself Again by Athena Novo Minted on Async Art, 2022 ... A 4-part series in the following order: 1. If Only You Were Yourself Again (2 artworks) 2. If Only You Were Not So Distant (24 artworks) 3. If Only The Blame Game Was Over (24 artworks) 4. If Only You Could Understand (24 artworks) The 4-parts are minted on Async Art.
